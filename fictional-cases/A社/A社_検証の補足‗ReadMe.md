【本実験でのハルシネーション発生について】

ここに掲載のA社のケーススタディは、AIを用いて「問題生成（GameMaster）」と「静的解析（コンサルタント）」を完全に分離して実験しました。

この過程で、GameMaster側が「見事にSRP違反（営業部への役割集中と依存）を第一の欠陥として指摘できた」という内容で、評価側がハルシネーションを起こす事象が発生しました。実際の診断レポートでは、SRPではなくISP・OCP・DIPがトップ3として選出されています。

当リポジトリでは、AIの出力をハルシネーションを含んだ『誤評価版』と、『再評価版』の両方を、起きたままの検証記録として公開します。

また、出題側ではハルシネーションに示すSRP違反を意図的に埋め込んだ「現状報告書」を作らせましたが、評価側はISP・OCP・DIPをトップ3として検出し、SRPは副次的な位置で検出するという、興味深い結果となっています。
